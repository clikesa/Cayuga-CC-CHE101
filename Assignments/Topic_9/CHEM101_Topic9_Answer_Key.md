### Section 1: Mole-Mole Calculations

**Problem 1:**
- **Answer:** $8.50 \text{ mol } \text{NH}_3$.
- **Reasoning:** $4.25 \text{ mol } \text{N}_2 \times (2 \text{ mol } \text{NH}_3 / 1 \text{ mol } \text{N}_2) = 8.50 \text{ mol}$.

**Problem 2:**
- **Answer:** $9.00 \text{ mol } \text{H}_2$.
- **Reasoning:** $6.00 \text{ mol } \text{NH}_3 \times (3 \text{ mol } \text{H}_2 / 2 \text{ mol } \text{NH}_3) = 9.00 \text{ mol}$.

**Problem 3:**
- **Answer:** $1.88 \text{ mol } \text{O}_2$.
- **Reasoning:** $2.50 \text{ mol } \text{Al} \times (3 \text{ mol } \text{O}_2 / 4 \text{ mol } \text{Al}) = 1.875 \text{ mol}$.

### Section 2: Mole-Mass Calculations

**Problem 4:**
- **Answer:** $12.1 \text{ g } \text{NH}_3$.
- **Reasoning:** $10.0 \text{ g } \text{N}_2 \div 28.02 \text{ g/mol} = 0.357 \text{ mol } \text{N}_2$. $0.357 \text{ mol } \times 2 = 0.714 \text{ mol } \text{NH}_3$. $0.714 \text{ mol } \times 17.03 \text{ g/mol} = 12.1 \text{ g}$.

**Problem 5:**
- **Answer:** $27.9 \text{ g } \text{Fe}$.
- **Reasoning:** $40.0 \text{ g } \text{Fe}_2\text{O}_3 \div 159.69 \text{ g/mol} = 0.250 \text{ mol } \text{Fe}_2\text{O}_3$. $0.250 \text{ mol } \times (4/2) = 0.500 \text{ mol } \text{Fe}$. $0.500 \text{ mol } \times 55.85 \text{ g/mol} = 27.9 \text{ g}$.

**Problem 6:**
- **Answer:** $245 \text{ g } \text{H}_2\text{O}$.
- **Reasoning:** $150 \text{ g } \text{C}_3\text{H}_8 \div 44.11 \text{ g/mol} = 3.40 \text{ mol } \text{C}_3\text{H}_8$. $3.40 \text{ mol } \times 4 = 13.6 \text{ mol } \text{H}_2\text{O}$. $13.6 \text{ mol } \times 18.02 \text{ g/mol} = 245 \text{ g}$.

### Section 3: Molar Solutions

**Problem 7:**
- **Answer:** $0.075 \text{ mol } \text{HCl}$.
- **Reasoning:** $0.750 \text{ mol/L} \times 0.100 \text{ L} = 0.075 \text{ mol}$.

**Problem 8:**
- **Answer:** $4.38 \text{ g } \text{NaCl}$.
- **Reasoning:** $0.300 \text{ mol/L} \times 0.250 \text{ L} = 0.075 \text{ mol}$. $0.075 \text{ mol } \times 58.44 \text{ g/mol} = 4.38 \text{ g}$.

**Problem 9:**
- **Answer:** $2.87 \text{ g } \text{AgCl}$.
- **Reasoning:** $0.200 \text{ mol/L} \times 0.100 \text{ L} = 0.020 \text{ mol } \text{AgNO}_3$. Ratio 1:1 $\rightarrow$ $0.020 \text{ mol } \text{AgCl}$. $0.020 \text{ mol } \times 143.32 \text{ g/mol} = 2.87 \text{ g}$.

### Section 4: Percent Yield

**Problem 10:**
- **Answer:** $84.8\%$.
- **Reasoning:** $(21.2 \div 25.0) \times 100\% = 84.8\%$.

**Problem 11:**
- **Answer:** $44.0 \text{ g}$.
- **Reasoning:** $50.0 \text{ g} \times 0.88 = 44.0 \text{ g}$.

**Problem 12:**
- **Answer:** $80.3\%$.
- **Reasoning:** Theoretical yield: $5.00 \text{ g } \text{H}_2 \div 2.02 \text{ g/mol} = 2.475 \text{ mol } \text{H}_2 \rightarrow 2.475 \text{ mol } \text{H}_2\text{O} \rightarrow 2.475 \times 18.02 = 44.6 \text{ g}$. Yield: $(40.0 \div 44.6) \times 100\% = 89.7\%$. 
- **Correction:** Calculation check: $(40.0/44.6) \times 100 = 89.7\%$.
