### Section 1: Mole-Mole Calculations
*Reference: Slides 5-6*

**Problem 1: Entry Level (Basic Ratio)**
Using the balanced equation $\text{N}_2 + 3\text{H}_2 \rightarrow 2\text{NH}_3$, how many moles of $\text{NH}_3$ are produced from $2.50 \text{ mol}$ of $\text{N}_2$?
- **Given:** $2.50 \text{ mol } \text{N}_2$.
- **Bridge:** Mole ratio from coefficients: $1 \text{ mol } \text{N}_2 \rightarrow 2 \text{ mol } \text{NH}_3$.
- **Calculate:** $2.50 \text{ mol } \text{N}_2 \times (2 \text{ mol } \text{NH}_3 / 1 \text{ mol } \text{N}_2) = 5.00 \text{ mol } \text{NH}_3$.
- **Check:** The ratio is 1:2, so the product should be double the reactant.
- **Result:** $5.00 \text{ mol } \text{NH}_3$.

**Problem 2: Medium Level (Inverse Ratio)**
Using the same equation ($\text{N}_2 + 3\text{H}_2 \rightarrow 2\text{NH}_3$), how many moles of $\text{H}_2$ are required to produce $4.00 \text{ mol}$ of $\text{NH}_3$?
- **Given:** $4.00 \text{ mol } \text{NH}_3$.
- **Bridge:** Mole ratio: $2 \text{ mol } \text{NH}_3 \rightarrow 3 \text{ mol } \text{H}_2$.
- **Calculate:** $4.00 \text{ mol } \text{NH}_3 \times (3 \text{ mol } \text{H}_2 / 2 \text{ mol } \text{NH}_3) = 6.00 \text{ mol } \text{H}_2$.
- **Check:** The ratio is 2:3. $4 \text{ mol}$ is double the coefficient of $\text{NH}_3$, so we need double the coefficient of $\text{H}_2$.
- **Result:** $6.00 \text{ mol } \text{H}_2$.

**Problem 3: Difficult Level (Identifying the Ratio)**
For the reaction $4\text{Al} + 3\text{O}_2 \rightarrow 2\text{Al}_2\text{O}_3$, how many moles of $\text{O}_2$ are needed to react completely with $1.25 \text{ mol}$ of $\text{Al}$?
- **Given:** $1.25 \text{ mol } \text{Al}$.
- **Bridge:** Mole ratio: $4 \text{ mol } \text{Al} \rightarrow 3 \text{ mol } \text{O}_2$.
- **Calculate:** $1.25 \text{ mol } \text{Al} \times (3 \text{ mol } \text{O}_2 / 4 \text{ mol } \text{Al}) = 0.938 \text{ mol } \text{O}_2$.
- **Check:** The ratio is 4:3, so we need slightly less $\text{O}_2$ than we have $\text{Al}$.
- **Result:** $0.938 \text{ mol } \text{O}_2$.

### Section 2: Mole-Mass Calculations
*Reference: Slides 8-9*

**Problem 4: Entry Level (Mass to Mass)**
Using $\text{N}_2 + 3\text{H}_2 \rightarrow 2\text{NH}_3$, how many grams of $\text{NH}_3$ are produced from $5.00 \text{ g}$ of $\text{N}_2$? (Molar masses: $\text{N}_2 = 28.02 \text{ g/mol}$, $\text{NH}_3 = 17.03 \text{ g/mol}$)
- **Step 1 (Grams $\rightarrow$ Moles):** $5.00 \text{ g } \text{N}_2 \div 28.02 \text{ g/mol} = 0.178 \text{ mol } \text{N}_2$.
- **Step 2 (Mole Ratio):** $0.178 \text{ mol } \text{N}_2 \times (2 \text{ mol } \text{NH}_3 / 1 \text{ mol } \text{N}_2) = 0.357 \text{ mol } \text{NH}_3$.
- **Step 3 (Moles $\rightarrow$ Grams):** $0.357 \text{ mol } \text{NH}_3 \times 17.03 \text{ g/mol} = 6.08 \text{ g}$.
- **Result:** $6.08 \text{ g } \text{NH}_3$.

**Problem 5: Medium Level (Reverse Roadmap)**
How many grams of $\text{Fe}$ are needed to produce $20.0 \text{ g}$ of $\text{Fe}_2\text{O}_3$ in the reaction $4\text{Fe} + 3\text{O}_2 \rightarrow 2\text{Fe}_2\text{O}_3$? (Molar masses: $\text{Fe} = 55.85 \text{ g/mol}$, $\text{Fe}_2\text{O}_3 = 159.69 \text{ g/mol}$)
- **Step 1 (Grams $\rightarrow$ Moles):** $20.0 \text{ g } \text{Fe}_2\text{O}_3 \div 159.69 \text{ g/mol} = 0.125 \text{ mol } \text{Fe}_2\text{O}_3$.
- **Step 2 (Mole Ratio):** $0.125 \text{ mol } \text{Fe}_2\text{O}_3 \times (4 \text{ mol } \text{Fe} / 2 \text{ mol } \text{Fe}_2\text{O}_3) = 0.250 \text{ mol } \text{Fe}$.
- **Step 3 (Moles $\rightarrow$ Grams):** $0.250 \text{ mol } \text{Fe} \times 55.85 \text{ g/mol} = 13.96 \text{ g}$.
- **Result:** $13.96 \text{ g } \text{Fe}$.

**Problem 6: Difficult Level (Multi-Step Synthesis)**
In the reaction $\text{C}_3\text{H}_8 + 5\text{O}_2 \rightarrow 3\text{CO}_2 + 4\text{H}_2\text{O}$, if $100 \text{ g}$ of $\text{C}_3\text{H}_8$ is burned, how many grams of $\text{H}_2\text{O}$ are produced? (Molar masses: $\text{C}_3\text{H}_8 = 44.11 \text{ g/mol}$, $\text{H}_2\text{O} = 18.02 \text{ g/mol}$)
- **Step 1:** $100 \text{ g } \text{C}_3\text{H}_8 \div 44.11 \text{ g/mol} = 2.267 \text{ mol } \text{C}_3\text{H}_8$.
- **Step 2:** $2.267 \text{ mol } \text{C}_3\text{H}_8 \times (4 \text{ mol } \text{H}_2\text{O} / 1 \text{ mol } \text{C}_3\text{H}_8) = 9.068 \text{ mol } \text{H}_2\text{O}$.
- **Step 3:** $9.068 \text{ mol } \text{H}_2\text{O} \times 18.02 \text{ g/mol} = 163.4 \text{ g}$.
- **Result:** $163.4 \text{ g } \text{H}_2\text{O}$.

### Section 3: Molar Solutions
*Reference: Slides 11-12*

**Problem 7: Entry Level (Volume to Moles)**
How many moles of $\text{HCl}$ are in $250 \text{ mL}$ of a $0.500 \text{ M}$ solution?
- **Given:** $V = 0.250 \text{ L}$; $M = 0.500 \text{ mol/L}$.
- **Bridge:** $\text{moles} = \text{Molarity} \times \text{Volume}$.
- **Calculate:** $0.500 \text{ mol/L} \times 0.250 \text{ L} = 0.125 \text{ mol}$.
- **Result:** $0.125 \text{ mol } \text{HCl}$.

**Problem 8: Medium Level (Molarity to Mass)**
What mass of $\text{NaCl}$ is needed to prepare $500 \text{ mL}$ of a $0.150 \text{ M}$ solution? (Molar mass $\text{NaCl} = 58.44 \text{ g/mol}$)
- **Step 1 (Volume $\rightarrow$ Moles):** $0.150 \text{ mol/L} \times 0.500 \text{ L} = 0.075 \text{ mol } \text{NaCl}$.
- **Step 2 (Moles $\rightarrow$ Grams):** $0.075 \text{ mol } \times 58.44 \text{ g/mol} = 4.38 \text{ g}$.
- **Result:** $4.38 \text{ g } \text{NaCl}$.

**Problem 9: Difficult Level (Solution Stoichiometry)**
$50.0 \text{ mL}$ of $0.100 \text{ M } \text{AgNO}_3$ reacts with $\text{NaCl}$. How many grams of $\text{AgCl}$ precipitate will form? ($\text{AgNO}_3 + \text{NaCl} \rightarrow \text{AgCl} + \text{NaNO}_3$; Molar mass $\text{AgCl} = 143.32 \text{ g/mol}$)
- **Step 1 (Volume $\rightarrow$ Moles):** $0.100 \text{ mol/L} \times 0.0500 \text{ L} = 0.00500 \text{ mol } \text{AgNO}_3$.
- **Step 2 (Mole Ratio):** Ratio is 1:1 $\rightarrow$ $0.00500 \text{ mol } \text{AgCl}$.
- **Step 3 (Moles $\rightarrow$ Grams):** $0.00500 \text{ mol } \times 143.32 \text{ g/mol} = 0.717 \text{ g}$.
- **Result:** $0.717 \text{ g } \text{AgCl}$.

### Section 4: Percent Yield
*Reference: Slides 13-14*

**Problem 10: Entry Level (Basic Yield)**
If a reaction has a theoretical yield of $10.0 \text{ g}$ but only $8.5 \text{ g}$ is collected, what is the percent yield?
- **Given:** Actual = $8.5 \text{ g}$; Theoretical = $10.0 \text{ g}$.
- **Bridge:** $\text{Percent Yield} = (\text{Actual} / \text{Theoretical}) \times 100\%$.
- **Calculate:** $(8.5 \div 10.0) \times 100\% = 85\%$.
- **Result:** $85\%$.

**Problem 11: Medium Level (Finding Actual Yield)**
A reaction with a theoretical yield of $25.0 \text{ g}$ has a percent yield of $72\%$. What was the actual yield?
- **Given:** Theoretical = $25.0 \text{ g}$; Yield = $0.72$.
- **Calculate:** $\text{Actual} = \text{Theoretical} \times \text{Yield} = 25.0 \text{ g} \times 0.72 = 18.0 \text{ g}$.
- **Result:** $18.0 \text{ g}$.

**Problem 12: Difficult Level (Full Chain: Mass $\rightarrow$ Theoretical $\rightarrow$ Percent)**
In the reaction $2\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$, $2.00 \text{ g}$ of $\text{H}_2$ is reacted. If $16.0 \text{ g}$ of $\text{H}_2\text{O}$ is actually produced, what is the percent yield? (Molar masses: $\text{H}_2 = 2.02 \text{ g/mol}$, $\text{H}_2\text{O} = 18.02 \text{ g/mol}$)
- **Step 1 (Theoretical Yield):**
    - $2.00 \text{ g } \text{H}_2 \div 2.02 \text{ g/mol} = 0.99 \text{ mol } \text{H}_2$.
    - $0.99 \text{ mol } \text{H}_2 \times (2 \text{ mol } \text{H}_2\text{O} / 2 \text{ mol } \text{H}_2) = 0.99 \text{ mol } \text{H}_2\text{O}$.
    - $0.99 \text{ mol } \text{H}_2\text{O} \times 18.02 \text{ g/mol} = 17.84 \text{ g}$ (Theoretical).
- **Step 2 (Percent Yield):** $(16.0 \text{ g} \div 17.84 \text{ g}) \times 100\% = 89.7\%$.
- **Result:** $89.7\%$.
