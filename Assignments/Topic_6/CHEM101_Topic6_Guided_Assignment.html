CHEM 101 Topic 6: Names and Formulas
Guided Assignment

Instructions: This assignment focuses on the translation between chemical names and formulas, covering ionic compounds, binary molecular compounds, acids, and hydrates. To get the most out of this exercise, please work through these solutions yourself on a separate sheet of paper. Practice using the analysis steps (Identify → Classify → Translate → Check) for each problem to build your muscle memory before attempting the graded problem set for Topic 6.
Section 1: Naming Ionic Compounds (Fixed-Charge Metals)
Problem 1: Entry Level (Binary Ionic) Name the compound LiBr.
Identify: Li is a Group 1 metal (+1); Br is a nonmetal (Group 17). Classify: Fixed-charge ionic compound. Translate: Cation is lithium; Anion is bromine → bromide.
Result: Lithium bromide.
Problem 2: Medium Level (Writing Formulas) Write the chemical formula for Magnesium oxide.
Identify: Magnesium (Mg) is Group 2 (+2); Oxide (O) is Group 6 (-2). Classify: Fixed-charge ionic compound. Translate: Mg2+ and O2- balance in a 1:1 ratio.
Result: MgO.
Problem 3: Difficult Level (Aluminum Compounds) Write the formula for Aluminum sulfide.
Identify: Aluminum (Al) is always +3; Sulfur (S) is Group 16 (-2). Classify: Fixed-charge ionic compound. Translate: To balance +3 and -2, the least common multiple is 6. We need two Al3+ ions (+6 total) and three S2- ions (-6 total).
Result: Al2S3.
Section 2: Variable-Charge Metals & Polyatomic Ions
Problem 4: Entry Level (Polyatomic Naming) Name the compound KNO3.
Identify: K is potassium (+1); NO3 is the nitrate polyatomic ion (-1). Classify: Ionic compound with a polyatomic ion. Translate: Potassium + nitrate. (Note: polyatomic names do not change to "-ide").
Result: Potassium nitrate.
Problem 5: Medium Level (Roman Numerals) Name the compound CuCl2.
Identify: Cu is a transition metal (variable charge); Cl is chloride (-1). Classify: Variable-charge ionic compound. Translate: There are two Cl- ions (-2 total). Therefore, the single Cu ion must be +2. This is written as copper(II).
Result: Copper(II) chloride.
Problem 6: Difficult Level (Formula with Polyatomic) Write the formula for Iron(III) carbonate.
Identify: Iron(III) is Fe3+; Carbonate is CO32-. Classify: Variable-charge ionic compound with a polyatomic ion. Translate: To balance +3 and -2, we need two Fe3+ (+6) and three CO32- (-6).
Result: Fe2(CO3)3.
Section 3: Binary Molecular Compounds (Nonmetals)
Problem 7: Entry Level (Prefixes) Name the compound CO2.
Identify: C and O are both nonmetals. Classify: Binary molecular compound. Translate: 1 Carbon (skip "mono-"); 2 Oxygens → dioxide.
Result: Carbon dioxide.
Problem 8: Medium Level (Writing Formulas) Write the formula for Dinitrogen pentoxide.
Identify: Di-nitrogen (2 N); Penta-oxide (5 O). Classify: Binary molecular compound. Translate: Combine the counts directly into subscripts.
Result: N2O5.
Problem 9: Difficult Level (Prefix Nuance) Name the compound P2O3.
Identify: P and O are both nonmetals. Classify: Binary molecular compound. Translate: 2 Phosphorus → diphosphorus; 3 Oxygens → trioxide.
Result: Diphosphorus trioxide.
Section 4: Acids, Salts, and Hydrates
Problem 10: Entry Level (Binary Acids) Name the acid HCl(aq).
Identify: Hydrogen + one nonmetal (Chlorine). Classify: Binary acid. Translate: "hydro-" + root (chlor) + "-ic acid".
Result: Hydrochloric acid.
Problem 11: Medium Level (Oxyacids) Name the acid HNO3.
Identify: Hydrogen + Nitrate (NO3-). Classify: Oxyacid (from an "-ate" ion). Translate: Nitrate ends in "-ate", so it becomes "-ic acid" → nitric acid.
Result: Nitric acid.
Problem 12: Difficult Level (Hydrates) Name the compound MgCl2 · 6H2O.
Identify: Ionic compound (MgCl2) + 6 water molecules. Classify: Hydrate. Translate: Ionic part: magnesium chloride; Hydrate part: 6 → hexa + "hydrate".
Result: Magnesium chloride hexahydrate.
